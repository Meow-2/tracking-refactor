### 简介

该程序为数字钢卷跟踪服务，是一个多线程程序，负责监听mqtt的消息，来判断其中的点位值是否发生变化，根据接收的消息和变化的情况，处理数据并调用第三方接口。

该程序在设计上适配多个不同机组，部署时，各机组一个实例，通过yml配置来确定当前机组代码，每个机组上都具有过程跟踪、剪切跟踪、开卷跟踪、焊接跟踪、切边跟踪功能，通过redis配置来决定是否开启。

### 主体功能

1. redis配置读取：根据所属机组从Redis中读取该机组最新的程序配置，每个机组都有自己的过程跟踪、剪切跟踪、开卷跟踪、焊接跟踪、切边跟踪功能配置
2. 多线程：每个跟踪功能的线程互相独立
3. mqtt消息订阅与处理：每个跟踪功能根据redis配置订阅一个mqtt主题消息，该主题的每条消息都要进行处理，但redis中只需要缓存该主题最新的一条消息。当收到消息时，要将该消息和Redis缓存的消息（即上一条消息），通过rocketmq传递给数据处理模块，之后redis缓存更新为最新消息
4. 数据处理与转发：解析传来的数据，对于不同跟踪功能的数据进行不同的处理
   1. 异常数据检测：空数据和异常波动的数据
   2. 点位数据比对：最新的点位数据和上一条点位的数据进行比对，从而触发不同逻辑
   3. 调用第三方接口：不同条件下调用不同第三方接口
   4. 第三方接口异常处理
      1. 失败1-3次：立即重试，指数退避
      2. 失败4-10次：加入本地重试队列，后台定时重试
      3. 失败10次：持久化到redis

### 额外功能

#### redis配置热更新

支持调用第三方接口，获取redis配置，并更新到redis。第三方接口的数据到redis配置中间可能还需要一层转换

#### 数据重跟踪

支持从第三方时序库查询历史数据，并进行重跟踪

#### 异常数据检测

空数据和异常波动的数据持久化到pg数据库

#### 日志

详细的方便对不同线程进行调试的控制台日志和持久化日志

#### Redis常化酸洗过程跟踪配置示例

tracking:cp1:process:config

```json
{
  //必填
  "enable": true,
  //必填
  "mqtt_topic": "cp1_process_tracking",
  //必填
  "tracking": {
    //必填
    "point_prefix": "/aygg_tracking/cp1/process/tracking/",
    //可选
    "start_condition": {
      "point": "speed",
      "threshold": 0.7
    },
    //必填，焊缝模式，卷取机模式，轧机模式
    "length_mode": "welder", //welder/coiler/rolling
    //可选，轧机模式才生效
    "rolling": {
      //轧制方向为true或1，默认为从左到右
      "direct_point":"轧制方向点位",
      "pass_no_point":"道次点位",
      //轧制方向是否要取反
      "direct_reverse": false,
    },
    //必填
    "points": [
      {
        //必填，数组或单个点位，welder模式为数组
        "length":[
          "group1_head_distance_to_wsd1_length",
          "group1_head_distance_to_wsd2_length"
        ],
        //必填
        "coil_no":"group1_coil_no",
        //可选，rolling模式下配合轧制方向，用来区分多个开卷机，多个卷取机
        "is_rolling_coiler": true
      },
      {
        "length":[
          "group2_head_distance_to_wsd1_length",
          "group2_head_distance_to_wsd2_length"
        ],
        "coil_no":"group2_coil_no",
        "is_rolling_coiler": true 
      },
    ]
  },
  //必填
  "segments": [
    {
      //必填
      "name": "sf",
      //必填
      "point_prefix": "/aygg_tracking/cp1/process/tech/sf/",
      //可选
      "length_correct": -50,
      //可选，焊机模式下确定用几号焊缝检测仪
      "length_array_index":0,
      //可选
      "points":[
        "sf_plate_temp",
        "sf_furnace_pressure"
      ]
    },
    {
      "name": "rtf",
      "length_correct": -80,
      "length_array_index":2,
      "points": [
        "rtf_plate_temp",
        "rtf_furnace_pressure"
      ]
    }
  ]
}
```

> welder/colier/rolling是不同的长度模式，决定了不同的数据处理算法
