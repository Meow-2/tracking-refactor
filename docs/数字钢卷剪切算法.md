## 剪切跟踪算法流程
配置读取：和其他跟踪算法逻辑相同，读取机组对应剪切算法的配置，订阅Mqtt主题。配置的主体结构和其他算法一样，包含enable、mqtt_topic、tracking三个部分。
tracking：
- point_prefix：点位前缀
    - mode：判别模式，连续线模式continuous，非连续线模式discontinuous
        - tail_experience：切尾量经验值，用来判断分切和切尾的情况
        - uncoiler_shear_point：开卷机侧剪切点位数组，每个元素是一个开卷机对应剪刀的配置
            - name：剪切点位名称
            - type：剪切点位类型
            - normal_pos：剪切点位处于正常位时对应的值，根据剪切点位值的变化和该值判断是否发生剪切事件
            - por_tr_code：该剪刀对应的开卷机/卷取机代码，用于在status跟踪算法构建的runtime上下文中取到对应开卷机/卷取机的钢卷号/颜色号
            - shear_settings：剪切参数设置，支持多层的默认值，用于计算切头、切尾、分切情况下的剪切长度
                - default：默认剪切类型，固定为null/head/tail/slice，非空时，表示跳过剪切类型判断，直接取对应剪切类型的数据
                - head：当剪切类型为head时，通过head下的length点位获取剪切长度
                - tail：当剪切类型为tail时，通过tail下的length点位获取剪切长度
            - grating_points：光栅点位设置，用于非连续线discontinuous判断剪切类型，内含has_coil配置，表示光栅占位时点位对应的值
            - color_point：颜色号点位设置，用于连续线continuous判断剪切类型
        - coiler_shear_point：卷取机侧剪切点位数组，每个元素是一个卷取机对应剪刀的配置，其下配置同uncoiler_shear_point，除了shear_settings中多了两个配置：
            - front_welder：用于连续生产线卷取机侧切尾，配置取样片数、废料片数；片长相同时配置length，片长不同时分别配置sample_length、scrap_length
            - behind_welder：用于连续生产线卷取机侧切头，配置规则同front_welder
上下文数据构建于发送：生产者根据构建上下文数据发送给消费者
剪切跟踪算法：消费者根据上下文数据，判断是否发生了剪切，若发生剪切事件，则推断本次剪切类型，剪切记录存数据库表。整个过程同时也要记录shear的runtime内存，收到的status的runtime上下文里面会包含`candidates`和`current`，shear要在其各个开卷机/卷取机元素的基础上，记录各个钢卷号上的各个剪切类型的完整剪切次数和当次剪切的刀数和最近一刀的开卷机剩余长度`head:{shear_no:0,cut_no:0,last_remain_length:0}`。当各个钢卷号改变时，该钢卷号的`shear_no`、`cut_no`清零。当剪切事件发生，判断出了剪切类型后，要计算 当前的剩余长度与last_remain_length的变化，若变化小于配置中的 shear_experience 则说明剪切事件是一次完整剪切中的一刀，cut_no+1，last_remain_length更新；否则说明是一个新的完整剪切，shear_no+1，cut_no置为1，last_remain_length更新
判断是否发生了剪切事件：剪切信号值的变化来判断，当前是否发生了剪切事件，若发生了剪切事件则继续，否则算法退出。
剪切类型判断与数据存储：根据配置信息中的模式类别，通过配置读取mqtt消息中各个所需点位的值，来判断当前发生的剪切事件属于哪种剪切类型；配置信息中的模式类别有两种，一种是连续线模式、一种是非连续线模式：
连续线模式：
a. 优先读取当前剪刀的`shear_settings.default`。若该值非空，则跳过后续判断，直接使用配置的`head`、`tail`或`slice`作为剪切类型。
    b. 开卷机侧剪切：通过`por_tr_code`从status跟踪算法构建的runtime上下文中获取`candidates`对应开卷机的钢卷颜色、剩余长度，并获取`current`当前卷取机的钢卷颜色；通过`color_point`获取剪刀靠近开卷机侧的颜色号。对应开卷机为开卷机，当前卷取机为卷取机，por、tr相关字段从中取得，shear_time取数据receiveAt
        i. 切头`head`：对应开卷机的钢卷颜色!=当前卷取机的钢卷颜色 && 剪刀靠近开卷机侧的颜色号=对应开卷机的钢卷颜色。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应开卷机的。cut_no=1，shear_length=0；cut_no>1，shear_length取shear_settings中head的length
        ii. 切尾`tail`：满足以下任一条件：
            - 对应开卷机的钢卷颜色=当前卷取机的钢卷颜色 && 对应开卷机的剩余长度<=`tail_experience`；
            - 对应开卷机的钢卷颜色!=当前卷取机的钢卷颜色 && 剪刀靠近开卷机侧的颜色号!=对应开卷机的钢卷颜色。
数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取当前卷取机的。cut_no=1，shear_length=0；cut_no>1，shear_length取shear_settings中head的length
iii. 分切`slice`：对应开卷机的钢卷颜色=当前卷取机的钢卷颜色&&对应开卷机的剩余长度>`tail_experience`。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应开卷机。cut_no=1，shear_length=0，否则取last_remain_length的变化量
    c. 卷取机侧剪切（出口飞剪）：通过`por_tr_code`从status跟踪算法构建的runtime上下文中获取`candidates`对应卷取机的钢卷颜色、剩余长度，通过`color_point`获取活套颜色。对应卷取机机为卷取机，当前开卷机为开卷机，por、tr相关字段从中取得，shear_time取数据receiveAt
        i. 切尾`tail`: 对应卷取机的钢卷颜色!=活套颜色 && cut_no <= shear_settings中front_welder中的(sample_pieces+scrap_pieces+1)。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应卷取机。cut_no=1，shear_length=0；配置单一length时直接取length，否则按当前片序落在取样片或废料片范围选择sample_length或scrap_length
        ii. 切头`head`:对应卷取机的钢卷颜色!=活套颜色 &&  cut_no > shear_settings中front_welder中的(sample_pieces+scrap_pieces+1)。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取当前开卷机；剪切长度按behind_welder中的length或sample_length/scrap_length规则取得
        iii. 分切`slice`。对应卷取机的钢卷颜色==活套颜色。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应卷取机。cut_no=1，shear_length=0，否则取last_remain_length的变化量
非连续线模式：
d. 优先读取当前剪刀的`shear_settings.default`。若该值非空，则跳过后续判断，直接使用配置的`head`、`tail`或`slice`作为剪切类型。例如CBL1出口剪配置为`slice`，触发后直接按分切处理。
    e. 根据每个`grating_points`元素的`has_coil`判断对应光栅当前是否被钢卷占位，并按光栅从剪刀到开卷机/卷取机的排列顺序判断占位是否连续。
    f. 开卷机侧剪切：通过`por_tr_code`从runtime上下文中获取对应开卷机原料卷号、剩余长度，并获取当前卷取机原料卷号。对应开卷机为开卷机，当前卷取机为卷取机，por、tr相关字段从中取得，shear_time取数据receiveAt
        i. 切头`head`：开卷机原料卷号!=卷取机原料卷号，并且入口剪到开卷机之间的光栅连续占位。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应开卷机的。cut_no=1，shear_length=0；cut_no>1，shear_length取shear_settings中head的length
        ii. 切尾`tail`：满足以下任一条件：
            - 开卷机原料卷号=卷取机原料卷号，并且开卷机剩余钢卷长度<`tail_experience`；数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取当前卷取机的。cut_no=1，shear_length=0；cut_no>1，shear_length取shear_settings中tail的length
            - 开卷机原料卷号!=卷取机原料卷号，并且入口剪到开卷机之间的光栅不连续占位。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取当前卷取机的。cut_no=1，shear_length=0；cut_no>1，shear_length取shear_settings中tail的length
        iii. 分切`slice`：开卷机原料卷号=卷取机原料卷号，并且开卷机剩余钢卷长度>=`tail_experience`。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应开卷机。cut_no=1，shear_length=0，否则取last_remain_length的变化量
    g. 卷取机侧剪切：通过`por_tr_code`从runtime上下文中获取对应卷取机原料卷号，并获取当前开卷机原料卷号。对应卷取机为卷取机，当前开卷机为开卷机，por、tr相关字段从中取得，shear_time取数据receiveAt
        i. 切头`head`：开卷机原料卷号!=卷取机原料卷号，并且出口剪到卷取机之间的光栅不连续占位。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取当前开卷机的。cut_no=1，shear_length=0；cut_no>1，shear_length取shear_settings中head的length
        ii. 切尾`tail`：开卷机原料卷号!=卷取机原料卷号，并且出口剪到卷取机之间的光栅连续占位。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应卷取机的。cut_no=1，shear_length=0；cut_no>1，shear_length取shear_settings中tail的length
        iii. 分切`slice`：开卷机原料卷号=卷取机原料卷号。数据存储：in_mat_no、in_mat_prod_no、shear_no、cut_no取对应卷取机的。cut_no=1，shear_length=0，否则取last_remain_length的变化量
