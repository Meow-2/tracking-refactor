# 两份方案关键内容提炼

## 一句话理解

“数字钢卷”不是一条钢卷主数据记录，而是一套把物料血缘、加工过程时序、等长切片、剪切损耗、表面缺陷及坐标方向统一关联起来的全生命周期数字模型。

## 两份文档的关系

- 《数字钢卷构建方案》是总体设计，覆盖数据范围、物料跟踪、切片跟踪、剪切事件、坐标变换、存储结构和实施计划。
- 《剪切信号处理及钢卷坐标变化情况设计方案》是专项细化，重点展开总体方案中的剪切信号识别和坐标换算规则。

## 总体方案的核心设计

1. **建立稳定的物料身份与血缘。** 以物料跟踪号标识血缘实体，以“物料跟踪号 + 加工顺序号”形成物料标识码；用关系表表达正常流转、分卷、并卷和混钢坯等关系。
2. **同时保存原始过程数据和切片数据。** 每个机组或加工单元永久保存在线卷时序数据、出口卷等长切片数据；跨机组追溯时再生成对齐后的切片数据。
3. **用实际厚度比处理轧制延伸。** 文档倾向于保留原始时序，钢卷下线后先切片；末道次完成后按实际厚度比重新划分前序机组切片，使各工序最终能按统一长度（示例为 1 m）对齐。
4. **把剪切结果纳入钢卷数字模型。** 记录切头、切尾、分切切废、左右切边量，并与物料号、生产次数、加工单元和切片数据关联。
5. **统一缺陷坐标。** 使用“上下、左右、头尾”三组二值变化量描述开卷和卷取造成的方向变化；多工序坐标变化可逐工序叠加，从而把任一工序发现的缺陷换算到原始卷或成品卷坐标。

## 剪切信号专项规则

- **入口剪、出口剪：**主要结合开卷机/卷取机原料卷号、光栅是否连续占位、开卷机剩余长度及经验阈值，区分切头、切尾和分切。
- **入口双层剪：**使用开卷机、卷取机及剪刀两侧的钢卷颜色辅助判断剪切归属。
- **连续线飞剪：**切焊缝时同时产生前卷切尾和后卷切头；长度由取样片、废料片、焊缝废料片数量和单片长度计算。
- **圆盘剪：**左右边部剪切量按 `(开卷机钢卷宽度 - 圆盘剪设定宽度) / 2` 计算。
- **分切判定：**以当前原料卷最大分切序号、剩余长度差和“最大分切切废量”阈值，判断一次剪切属于上一分切的切废，还是新子卷的开始。

## 实施时最值得关注的问题

- 文档中的若干表仍是概念结构，部分字段名、类型、主键和约束尚未最终确定。
- “方案四”最完整，但需要保留全量原始时序并在末道次后重算前序切片，计算量、存储量和幂等更新规则需要进一步设计。
- 分切判断依赖经验阈值与现场信号质量，应明确边界值、信号抖动、重复触发、乱序、缺失和人工修正机制。
- 坐标变换适合用三位布尔向量实现；跨工序叠加本质上可用异或运算，但需要确认“机组是否同侧”、直通、返修和半卷回退等特殊路径。
- 原文已指出孔洞数据结构、焊缝废料、重复生产、半卷回退及多维度平台配置能力等遗留问题，这些会直接影响最终数据模型和接口契约。

## 建议的阅读顺序

先看总体方案的“2.1 工序间物料跟踪”，理解物料身份和血缘；再看“2.2 切片跟踪”，理解长度映射；最后看专项文档，把剪切事件和坐标变换代入前两部分。这样最容易形成完整心智模型。
