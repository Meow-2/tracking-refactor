## 1. 核心服务设计

### 1.1 物料预处理服务

#### 服务职责

- 从L3物料档数据表读取
- 解析并处理分卷/并卷场景
- 维护物料跟踪号和顺序号
- 生成机组间/机组内物料关系

#### 处理流程,可替换为时序图

```text
定时任务/事件触发
   │
   ▼
读取L3物料档表（mm_mat_management）
   │
   ▼
识别生产场景
   ├─ 非分卷/并卷场景：同一跟踪号，一个入口材料号，一个出口材料号
   ├─ 分卷场景：多条记录中，同一跟踪号、入口材料号可关联多个出口材料号；分卷顺序：以出口材料号倒数第二位作为分卷标识位，标识子卷顺序
   └─ 并卷场景：单条记录中，同一出口材料号关联跟踪号、入口材料号中多个数据。入口材料号以逗号分隔存储所有并卷子卷的出口材料号，跟踪号同样以逗号分隔存储对应并卷子卷跟踪号，重复跟踪号据实重复录入；并卷顺序：按照入口材料号逗号分隔的排列次序为准
   │
L3物料档表新增数据需考虑分卷场景下，后面几个子卷数据还未产出，产出时需要更新已记录的质量物料档数据 
   │
   ▼
生成/维护物料跟踪号和顺序号
   ├─ 非分卷/并卷场景：跟踪号不变，顺序号 + 1
   ├─ 分卷场景：新的跟踪号，顺序号从1开始
   └─ 并卷场景：新的跟踪号，顺序号从1开始
   │
   ▼
写入数据库
   ├─ 质量物料档表
   ├─ 机组间物料关系表
   └─ 机组内物料关系表
```

### 1.2 跟踪服务

#### 服务职责

- 实时接收生产线数据（Redis）
- 跟踪钢卷位置和状态
- 采集生产过程参数、剪切结果、焊接数据、缺陷数据
- 异常点检测：发现数据异常波动、缺失值等情况并记录
- 支持对历史时序数据的重新跟踪
- 调用数字钢卷服务API存储结果

#### 部署模式

- **每机组独立部署**：1#焊接、1#重卷、1#20辊轧机、1#常化酸洗、1#切边各一个实例

#### 处理流程

```text
启动加载
   │
   ├─ 加载跟踪位置配置
   ├─ 加载参数配置
   └─ 连接Redis读取数据
   │
实时数据处理循环
   │
   ├─ 焊缝跟踪+过程参数
   │    └─ 在线卷过程跟踪数据
   │
   ├─ 剪切事件
   │    ├─ 入出口剪切明细
   │
   ├─ 切边事件
   │    ├─ 圆盘剪状态变化停止->启动、启动->停止，记录实绩；圆盘剪启动状态下，钢卷号变化记录实绩
   │
   ├─ 焊接事件
   │    └─ 记录焊接参数
   │
   ├─ 开卷+卷取事件
   │    └─ 开卷方式+卷取方式
   │
数据输出
   ├─ 在线卷过程跟踪数据 ──▶ 调用数字钢卷服务API
   ├─ 开卷+卷取方式 ──▶ 调用数字钢卷服务API
   ├─ 入出口剪切明细 ──▶ 调用数字钢卷服务API
   ├─ 焊接结果 ──▶ 调用数字钢卷服务API
   ├─ 切边实绩 ──▶ 调用数字钢卷服务API
```

#### 异常处理机制

```text
API调用失败处理：
   │
   ├─ 失败1-3次：立即重试，指数退避
   ├─ 失败4-10次：加入本地重试队列，后台定时重试
   └─ 失败10次：持久化到redis
```

#### 异常点检测

```text
异常检测类型：
   │
   ├─ 数据缺失检测：检查时序数据是否有连续缺失或异常间隔
   ├─ 异常波动检测：通过标准差、变异系数等统计方法检测数据异常波动

异常处理流程：
   │
   ├─ 检测到异常点后记录异常信息（异常类型、异常值、时间戳、位置）
   ├─ 标记该钢卷存在异常数据
   ├─ 将异常信息存储到异常记录表
   └─ 提供异常数据查询和告警接口

异常记录表结构：
   │
   ├─ 异常ID
   ├─ 物料号
   ├─ 机组代码
   ├─ 参数名
   ├─ 异常类型
   ├─ 异常值
   ├─ 长度范围
   └─ 检测时间
```

### 1.3 数字钢卷服务

#### 服务职责

- 在线卷过程跟踪数据转化为出口卷切片数据
- 表检缺陷按片重新记录与输出，前序缺陷继承处理（重新生成或剪切掉）
- 跨加工单元对齐切片处理
- 按切片序号查询钢卷实际起止长度

#### 处理流程

##### 流程1：出口卷切片数据处理

```text
接收到在质量物料档数据
   │
   ▼
确定切片参数（切片长度）
   │
   ▼
基于在线卷跟踪数据将整个钢卷按定长划片
   │
   ├─ 计算每个切片的起止长度
   └─ 为每片重新插值聚合计算生产过程参数值
   │
   ▼
处理表检缺陷数据
   ├─ 根据表面翻转调整缺陷表面信息
   ├─ 根据切头尾量和切边量判断缺陷是否被切除
   └─ 对保留的缺陷按片重新记录明细
   │  
处理跟踪生产信息
   ├─ 切头切尾量
   ├─ 左右切边量
   └─ 速度：符合机组工艺要求速度范围，窗口期最长的工艺速度
   │
   ▼
输出结果
   ├─ 出口卷切片时序数据表
   └─ 缺陷关系表
```

##### 流程2：跨加工单元对齐切片处理

```text
接收对齐请求：
  - 开始加工单元
  - 结束加工单元
  - 物料跟踪号
  - 生产次数号

▼

查询中间所有加工单元

▼

获取各机组的物料关系数据（机组内物料关系表、机组间物料关系表）

▼

处理所有变换情况：

  情况1：切头处理
    - 判断切片是否在切头范围内
    - 切头范围内的切片标记为已切除
    - 调整有效切片的位置

  情况2：切尾处理
    - 判断切片是否在切尾范围内
    - 切尾范围内的切片标记为已切除
    - 调整有效切片的位置

  情况3：切边处理
    - 根据切边量调整缺陷宽度位置
    - 判断缺陷是否被切边切除
    - 标记已切除或保留

  情况4：表面翻转处理
    - 根据开卷方式、卷取方式判断翻转规则
    - 上下翻转：改变缺陷上下表面
    - 左右翻转：调整缺陷宽度方向位置
    - 头尾翻转：调整缺陷长度方向位置

  情况5：分卷/并卷
    - 根据机组间物料关系确定入口物料在出口物料的位置范围
    - 建立不同加工单元切片之间的对应关系

▼

构建完整的对齐数据结构，包含所有加工单元的切片信息

▼

封装对齐后的数据，提供数据返回接口
```

### 1.4 质量管控服务

#### 服务职责

- 管理工艺规程和工艺参数、参数指标库、判定规则
- 执行参数指标计算与质量判定，支持二次计算与判定
- 物料追溯结果查询：参数指标/判定结果/参数曲线

#### 处理流程

##### 流程1:参数指标计算

```text
触发计算（定时/手动/实时）
   │
   ▼
获取待计算物料信息
   │
   ▼
获取参数指标库配置
   │
   ▼
遍历参数指标，筛选类别为"指标"的记录
   │
   ▼
对每个指标判断指标类型
   │
   ├─ 指标类型 ≠ "无"：
   │   └─ 直接按指标类型的计算函数计算（如：平均值、最大值、最小值、标准差、极差、命中率等）
   │
   └─ 指标类型 = "无"：
   │   ├─ 应用自定义条件
   │   └─ 按结果表达式计算
   │
   ▼
获取切片数据（或原始数据）
   │
   ▼
逐条计算参数指标
   │
   ▼
存储参数指标结果到关系表
```

##### **流程2:质量判定**

```text
触发判定（定时/手动/实时）
   │
   ▼
获取待判定物料信息
   │
   ▼
获取适用的判定规则（按品种规格匹配）
   │
   ▼
获取参数指标结果表数据
   │
   ▼
逐条执行判定规则
   │
   ├─ 阈值判定
   ├─ 匹配判定
   │
   ▼
汇总判定结果
   ├─ 合格/不合格
   └─ 判定详情
   │
   ▼
输出结果
	└─ 判定结果关系表
	└─ 缺陷关系表
```
