# 钢卷状态跟踪算法

Status 跟踪用于从多台开卷机、卷取机的“钢卷号 + 剩余长度”点位组合中识别当前运行设备。配置示例见 `docs/config/CP1/status.json`。

## 配置

- `tracking.start_condition`：点位值大于等于阈值时启用算法。
- `tracking.sample_count`：同一钢卷参与趋势判断所需的连续消息数，最小为 2。
- `tracking.min_length_change`：窗口首尾最小净变化量，必须大于等于 0。
- `tracking.points[].code/name`：设备唯一编码和展示名称。
- `tracking.points[].side`：`uncoiler` 表示开卷机，`coiler` 表示卷取机。
- `tracking.points[].coil_no/remaining_length`：设备钢卷号和剩余长度点位。

## 判定与输出

每个设备只保留当前钢卷最近 `sample_count` 个长度值。卷号变化时重新开始采样，卷号或长度无效时清除该设备窗口。开卷机要求窗口末值小于首值，卷取机要求窗口末值大于首值，同时绝对净变化量需达到阈值；中间帧允许抖动。

同一端有多个候选时选择绝对净变化量最大的设备，并列时使用配置顺序。每条消息固定产生开卷端、卷取端两条 `StatusResult`；无匹配或产线停机时对应结果 `running=false`，设备、卷号和长度为空。结果当前只写算法步骤日志，不写时序数据库。
